## About Davis Student Resource Compass

Davis Student Resource Compass is a web app designed to help UC Davis students locate campus support through a guided, map-based experience. It combines resource mapping with semantic matching so people can discover services that fit their needs without having to sort through unrelated results.

The interface is built for broad access and practical use, with multilingual support, accessibility-aware design, and a responsive layout that adapts across devices. It is especially useful for students, support staff, and community contributors who want a clearer way to surface and find on-campus help.

## Features

- Interactive campus map for visual resource exploration
- Semantic resource matching to connect needs with relevant services

- Real-time availability indicators for current resource status
